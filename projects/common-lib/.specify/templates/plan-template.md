Gates derived from `.specify/memory/constitution.md` (v2.0.0). Mark each PASS / FAIL / N/A;
every FAIL MUST be justified in Complexity Tracking.

- [ ] **I. Clean Architecture**: Four layers; Dependency Rule respected; no framework annotations
      in Domain; one class with one public method per use case; ports defined in Application
- [ ] **II. Clean Code**: Design keeps methods small, classes single-responsibility, no duplication
- [ ] **III. Stateless REST microservice**: Pure API; no session state; stays within the bounded
      context; inter-service calls are REST only; PostgreSQL is the only datastore
- [ ] **IV. API contracts**: `/api/v1/...` versioning; RFC 9457 errors; OpenAPI 3.1 documented with
      required roles; collections paginated with a max page size; mutations idempotent
- [ ] **V. TDD**: Test-first ordering planned; unit (no Spring), `@WebMvcTest`, `@DataJpaTest`, and
      `@SpringBootTest` on embedded PostgreSQL identified; query-count assertions; JaCoCo ≥ 80%
      line/branch for Domain + Application
- [ ] **VI. Security**: JWT resource server; required RBAC role(s) declared per endpoint;
      deny-by-default; no sensitive data in responses or logs
- [ ] **VII. Observability**: Custom metrics, trace propagation, and structured logs with
      correlation IDs identified
- [ ] **VIII. Resilience**: Timeouts, circuit breakers, and bounded pools for every outbound
      dependency
- [ ] **Persistence**: Schema changes as new Flyway migrations only; N+1 prevention planned
- [ ] **Dependencies**: Any library outside the approved stack is justified
